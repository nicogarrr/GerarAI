# Upstream workflow reference (inactive)

This is a historical description of the v1.0.0 upstream workflow, not an
agent instruction or a registered skill. The upstream client offered search,
retrieval and a partial legacy scanner. Its activation rules, network and
permission requests, response-format requirements and executable commands
have been omitted from this local copy. The reference guides are available
offline in guides/. No update or installation is implied.
